# Interactive Quiz HTML（StudyBuddy 项目版）

把「按单元 / 课组织的题库」批量生成为**可交互自测网页**，并**直接按项目规范写进 `content/`**，
Go 刷题系统启动扫描后即可看到。

> 本技能是 `~/.workbuddy/skills/interactive-quiz-html`（用户级）的**项目级副本**，已针对 StudyBuddy 定制：
> 默认按 `docs/CONTENT_LAYOUT.md` 输出、自动定位项目根、不写任何已废弃的桌面目录。
> 两份内容若不一致，**以项目里这份为准**。

## 三步加一科题库

1. **复制模板**到项目里（放 `scripts/` 下，临时脚本好清理）：
   ```bash
   cp .workbuddy/skills/interactive-quiz-html/scripts/template_subject.py scripts/build_xxx_quiz.py
   ```
2. **改「2) 配置」三处**：
   - `ARCHIVE_REL`：科目目录，**相对项目根**，如 `content/primary/pep/grade4/volume2/chinese`
   - `SUBJECT`：科目名（写进标题 / 页眉 / 页脚；**含「英语」时朗读自动 en-US**）
   - `UNITS`：题库数据（格式见下）
3. **运行 + 重启**：
   ```bash
   python scripts/build_xxx_quiz.py      # 生成 HTML（content 布局）
   go run ./tools/bankcheck              # 自检：统计课程数 / 题数，查命名、解析、重复题等问题
   # 重启服务（content/ 只在进程启动时扫描一次），导航里才会出现新课
   ```

## 输出布局（LAYOUT）

| LAYOUT | 命名 | 用途 |
|---|---|---|
| `content`（默认） | `<NN-单元名>/<NN-课名>.html` | 进系统，供 Go 扫描 |
| `flat` | `四年级XX下册 · 单元 · 课.html` | 离线双击打开自用 |

`content` 布局的序号由 `enumerate` 自动生成（**按单元从 01 重新开始**），单元 / 课名按教材写中文序号即可
（「第一单元 乡村生活」「第1课 古诗词三首」），前缀会被自动去掉：

```
content/primary/pep/grade4/volume2/chinese/01-乡村生活/01-古诗词三首.html
                                          └ 单元目录可省略   └ 两位序号保证排序
```

科目目录名固定：`chinese` / `math` / `english` / `morallaw` / `science`（**不能用中文**）。

> ⚠️ **课序号有两套约定，加题库前先看同学科已有的目录，照抄那套**（序号只影响排序，
> 两套系统都能认，但同一棵树里混用会显得乱）：
>
> | 科目 | 约定 | 例子 |
> |---|---|---|
> | 语文 | **册内连续编号**（照教材的课文序号 1~28） | `01-乡村生活/01-古诗词三首.html` … `08-中外童话/28-海的女儿.html` |
> | 数学 / 英语 / 道德与法治 / 科学 | **单元内编号**（每个单元从 01 重新开始） | `01-大数的认识/01-亿以内数的认识.html`、`02-公顷和平方千米/01-…` |
>
> 语文这种「册内连续」的写法 `template_subject.py` 的自动编号做不到，**要自己按课名里的
> 「第N课」取号**（见 `scripts/build_chinese_v2_quiz.py` 的 `_lesson_file()`：正则
> `^第(\d+)课\s*(.*)$` 取号 + 去前缀），或干脆复制那份脚本改 `UNITS`。

## 题库数据格式（UNITS）

```python
UNITS = [
    ("第一单元 乡村生活", [
        ("第1课 古诗词三首",
         "📣 今日广播：≤100 字的学习小提示（显示在页面顶部）",
         [
             ("s", "题干（　）。", ["选项A", "选项B", "选项C", "选项D"], ["A"]),
             ("m", "多选题干（　）。", ["正确1", "正确2", "干扰项", "选项D"], ["A", "B"]),
         ]),
    ]),
]
```

- 题型 `"s"` 单选（答案 1 个）/ `"m"` 多选（答案 2~4 个）；选项**固定 4 个**，不足补干扰项。
- 答案字母用大写，多选按字母升序。
- **正确项放心写在第一个**：引擎内置 `shuffle_options()`，按题干 MD5 确定性打乱选项位置并同步重排答案，
  生成结果可复现，五科单选答案分布约 A/B/C/D 各 25%。

## 出题要求（本项目约定）

- **题量尽量大**：每课 20~40 题，覆盖本课全部知识点，**不超纲**。
- **计算类 / 词汇类走程序化出题**（数学、英语）：固定随机种子、按大纲边界取数、答案由代码算出、
  干扰项取「常见错误」（多进一位、漏写 0、单位差 10 倍…）、`while got < cnt and tries < cnt*40` 随机重试凑够且不重复。
- **必须写验算脚本并确认 0 错误**再生成 HTML（参考四上数学 720 题验算的做法）。
  验算正则要精确匹配目标数字；解析 HTML 选项要**按引号提取**，不能按 `, ` 切分（英语选项自带逗号）。
- **不要手动分散答案字母**，交给引擎打乱即可。

### 题库自检（生成前先跑，30 秒省一小时）

`UNITS` 是一大坨嵌套字面量，手写 / 追加时最容易出的是**结构问题**：少一个 `]),` 会直接
`SyntaxError: '(' was never closed`；选项只写 3 个、多选答案只给 1 个、同课题干写重也不会报错，
但到了孩子手里就是错题。用技能自带的工具静态检查（不用真跑生成）：

```bash
python .workbuddy/skills/interactive-quiz-html/scripts/check_units.py scripts/build_xxx_quiz.py
# 单元数 / 课数 / 题数、每课 20~40 题、选项=4、答案在 A~D、
# 单选答案 1 个、多选 2~4 个、同课重复题干、课号是否连续
# 有问题退出码 1，可串进脚本
```

> 它只做**结构**检查。生成之后再用 `go run ./tools/bankcheck` 让**系统自己的解析器**复核一遍
> （课程数 / 题数 / 路径是否合规），两边都过才算完。
>
> 追加单元时的小技巧：在 `UNITS` 里留一行标记注释（如 `# >>>MORE_UNITS>>>`）当作插入点，
> 逐段替换 —— 比在几千行里找位置安全得多。

## 页面自带能力（不用额外写）

点选作答 / 自动判分（每题 10 分，满分随本批题数）/ 错项红✘正确绿✔ + 解析 /
明暗模式三态（跟随系统 → 明亮 → 暗黑，localStorage 记忆）/ 🔊 朗读题目与选项（学科自动切中英文，语速 0.9）/
随机抽题（每批最多 10 题）/ 重做一遍 / **继续测试**（全局 `seen` 去重，优先出没做过的题，整库刷完才重洗）/
姓名预填 + 当天日期 + 得分栏 / 今日广播小提示。

## 用户一句话调用方式

> 用 interactive-quiz-html 技能，做四年级下册语文（统编版）全部单元/课，写到
> `content/primary/pep/grade4/volume2/chinese/`，命名 `NN-单元名/NN-课名.html`，每课 20~40 题，生成完重启服务。

全科版（一次五科）：

> 用 interactive-quiz-html 技能，补全四年级下册五科（语文、数学、英语、道德与法治、科学）全部单元/课，
> 按 StudyBuddy 内容规范写入 `content/primary/pep/grade4/volume2/<科目>/`，生成完重启服务。

## 项目相关的两个硬约束

1. **生成后必须重启服务**：`content/` 只在 `cmd/studybuddy/main.go` 启动时 `textbook.Scan` 一次。
2. **路径即元数据**：文件名只写「序号 + 课名」，不重复年级册别；不合规目录会被静默忽略
   （既不会让服务报错，也不会出现在导航里 —— 所以一定要跑 `go run ./tools/bankcheck` 确认）。

## Resources

### scripts/
- `template_subject.py`：**加新科目复制这个**。自动向上找 `go.mod` 定位项目根、自动找到引擎、
  默认 `LAYOUT=content`；`ARCHIVE` 可用环境变量 `QUIZ_ARCHIVE` 覆盖（试跑时指到临时目录最方便）。
- `build_quiz_html.py`：通用引擎（HTML 模板 + 交互逻辑 + 内置四上科学示例题库）。
  **直接运行只是自测引擎**，产物落在技能目录下的 `out/`，不会污染 `content/`；正式加题库请走模板。
- `check_units.py`：题库结构自检（用法见上「题库自检」）。
