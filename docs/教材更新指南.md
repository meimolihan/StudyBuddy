# 教材更新指南

> 适用场景：`D:\ChinaTextbook`（ChinaTextbook 仓库）里的教材 PDF 更新了，
> 需要同步到 StudyBuddy。
> 最后验证：2026-10-03 / 图集 283 册（小学 111 / 初中 75 / 高中 97）

---

## 一、先判断属于哪种更新

| 情形 | 判断方法 | 走哪条流程 |
|---|---|---|
| **A. 教材内容换版**（同一册 PDF 被替换） | 体检能列出来 | 流程 1（最常见） |
| **B. 新增教材**（仓库多了新册） | 扫描后册数变多 | 流程 2 |
| **C. 教材被删除 / 改名** | 扫描后册数变少 | 流程 3 |
| **D. 首次部署 / 图集是旧版脚本产的** | 体检列出全部 283 册 | 跑一次 `--update` 补指纹 |

**教材改了内容/页数后，介绍与目录也要重新提取**（见流程 5）。

**先跑体检，它会直接告诉你属于哪种：**

```bash
cd C:/Users/meimo/Desktop/StudyBuddy
python tools/textbook-batch/render.py --check-source
```

输出「体检通过」= 图集与源文件一致，什么都不用做。
输出「源 PDF 已换版本、需要重新渲染的册：N 册」= 走流程 1。

---

## 流程 1：教材换版（最常见）

体检会精确列出哪几册要更新，然后：

```bash
# 增量更新：只重渲这几册，其余 280 多册一律跳过
python tools/textbook-batch/render.py --update

# 补高清（可选，高清按需生成，不急）
python tools/textbook-batch/render.py --hi-only primary-chinese-g4-v1,primary-math-g4-v1
```

**不需要重启服务。** manifest 按 mtime 热重载，刷新页面即可看到新图。

耗时参考：单册低清约 10 秒，高清约 5 分钟。

---

## 流程 2：新增教材

```bash
# 1. 重新扫描（只登记人教/统编版，其余自动过滤）
python tools/textbook-batch/scan.py --root "D:/ChinaTextbook" --out data/textbook

# 2. 核对输出：登记册数、多版本后缀、核心学科缺口
#    「核心学科（语文/数学/英语）小学与初中全年级齐备」= 没有缺口

# 3. 只渲染新增的册（新册没有 meta.json，会被自动识别；已有册不受影响）
python tools/textbook-batch/render.py

# 4. 需要高清时
python tools/textbook-batch/render.py --hi --stage primary
```

> 第 3 步不需要手动列 key：旧册的 `loReady` 为真会自动跳过。
> 若想确认只动了新册，先跑 `--check-source` 看清单。

---

## 流程 3：教材被删除或改名

改名会导致**键名变化**，旧图集目录变成孤儿（占磁盘但页面上不再显示）。

```bash
# 1. 重新扫描
python tools/textbook-batch/scan.py --root "D:/ChinaTextbook" --out data/textbook

# 2. 找出孤儿目录：manifest 里没有、但磁盘上还在的
python -c "import json,os; m=json.load(open('data/textbook/manifest.json',encoding='utf-8')); ks={b['key'] for b in m['books']}; [print('  ',d) for d in sorted(os.listdir('data/textbook')) if d!='manifest.json' and d not in ks]"

# 3. 确认上面列出的目录确实该删，再手动删除
```

**改名不会被自动识别成「更新」**——它是新键。必须重新扫描，
再删孤儿目录。不删只是浪费磁盘，不影响功能。

---

## 流程 4：强制重渲某几册

源文件没变、但想提升清晰度或怀疑图集损坏：

```bash
python tools/textbook-batch/render.py --force --only primary-math-g4-v1
python tools/textbook-batch/render.py --hi-only primary-math-g4-v1   # 只补高清
```

---

## 流程 5：重新提取「教材介绍」与「目录」

教材换了内容，介绍和目录也跟着变。`manifest.json` 里没有这两块，
它们在独立的 `data/textbook/curric.json` 里，由提取工具从 PDF 目录页解析。

```bash
# 全量提取（283 册，约 3~5 分钟）
python tools/textbook-batch/extract_curric.py --out data/textbook/curric.json

# 只处理某学段（更快）
python tools/textbook-batch/extract_curric.py --stage primary --out data/textbook/curric.json

# 只处理某几册
python tools/textbook-batch/extract_curric.py --only primary-math-g4-v1,primary-chinese-g4-v1
```

提取完**不需要重启服务**：`curric.json` 同样按 mtime 热重载，刷新页面即可。

**先体检再提取**（可选，但推荐，能提前看出哪些册解析不出来）：

```bash
python tools/textbook-batch/diag_toc.py --stage primary --stage middle --stage high
```

输出按「OK / 页码不足 / 未找到目录页」分组，`OK` 里能直接看到每册的
条目数、单元数、页码偏移和样例条目。

### 为什么有的册提不出目录

PDF 目录页排版差异很大，工具要同时应付：点线式（语文）、分行式、
课名与页码分列（数学）、标题列 + 页码列按序对应（英语）。
少数册（美术、音乐等）目录页本身就没有可解析的结构化条目，
这类只会补上「教材介绍」，目录位置显示"整理中"——这是预期行为，
不会拿不确定的数据凑数。

判定规则（写在 Go 侧 `internal/web/textbookres.go`）：
- 有目录但 `confidence < 0.5` → 不上架，避免页面上出现错页链接
- 没目录但有介绍 → 只显示介绍，目录区块显示"整理中"

### 目录为什么是懒加载

283 册 × 平均 100 课 ≈ 3 万条课目，内联进详情页首屏会让 HTML 涨到几百 KB。
所以详情页只内联**小目录**（估算 ≤ 4000 字符），大的走 `/textbook/toc` 异步取。
两个分支渲染的是同一套 `.tb-unit` / `.tb-lessons` 结构，视觉与交互完全一致。

## ⚠️ 关键坑（务必知道）

### 1. 不要跳过扫描直接渲染

改了源 PDF 却只跑 `render.py`（不加 `--update`），`manifest.json` 不会更新
`pages` 字段，册名/页数/分类都还是旧的。**每次更新都要先 `scan.py`。**

### 2. 页数变少时，`--force` 也要跟着

旧版脚本只按「图数量 ≥ 页数」判断是否完成。如果新版教材页数**变少**
（比如 138 页 → 130 页），旧图 138 张会被误判成"已完成"而跳过。
现在 `--update` 靠源文件指纹判断已经没这个问题；
但如果你手动改过 meta.json 或用老流程，请务必加 `--force`。

### 3. 高清图很占空间

高清 1400px 约占 5GB/全量。当前 1.6GB（图集 283 册）。
建议：小学全量补高清（`--hi --stage primary`），初中高中按需补。

### 4. 磁盘清理

```bash
du -sh data/textbook        # 看当前占用
```

## 常用命令速查

```bash
# 体检：源文件有没有变（更新前先跑这个）
python tools/textbook-batch/render.py --check-source

# 增量更新：只重渲换版本的册
python tools/textbook-batch/render.py --update

# 全量低清（新册自动补，已完成的跳过）
python tools/textbook-batch/render.py

# 按学段补高清
python tools/textbook-batch/render.py --hi --stage primary    # 小学
python tools/textbook-batch/render.py --hi --stage middle    # 初中
python tools/textbook-batch/render.py --hi --stage high      # 高中

# 指定册补高清
python tools/textbook-batch/render.py --hi-only key1,key2,key3

# 强制重渲
python tools/textbook-batch/render.py --force --only key1

# 重新扫描仓库
python tools/textbook-batch/scan.py --root "D:/ChinaTextbook" --out data/textbook

# 重新提取介绍与目录（教材换版后必跑）
python tools/textbook-batch/extract_curric.py --out data/textbook/curric.json

# 体检目录解析质量
python tools/textbook-batch/diag_toc.py --stage primary
```

## 验收清单

更新后逐条确认：

```bash
# 1. 体检通过
python tools/textbook-batch/render.py --check-source

# 2. 册数符合预期
python -c "import json; m=json.load(open('data/textbook/manifest.json',encoding='utf-8')); print(len(m['books']),'册')"

# 3. 页面能打开且图集可访问（需已登录）
#    浏览器打开 http://localhost:8658/textbook  点开任意一册翻几页
```

- [ ] 体检输出「体检通过」
- [ ] 册数符合预期
- [ ] 随机抽 2~3 册翻页正常（图清晰、无错页）
- [ ] 主页【官方教材】卡显示的是当前年级教材
- [ ] 服务无需重启（manifest 热重载生效）
