### 4.2 主题变量

游戏侧用 `--g-*` 变量，**每个都带浅色 fallback**：

```css
background:var(--g-bg,#f4f7fb);
color:var(--g-ink,#1f2937);
border-color:var(--g-line,#e3e9f1);
```

- 站点侧由 `game.go` 的 `gameThemeBridgeCSS()` 注入变量定义
- 跟随系统时包在 `@media (prefers-color-scheme: dark)` 内，不强加给浅色用户
- 直接双击 HTML 打开（不经站点）时靠 fallback 正常显示，不会白底白字

### 4.3 题库格式（与刷题题库完全一致）

```js
const ALL = [
  {t:"s",q:"「一、二、三」中的「一」有几画？",o:["1 画","2 画","3 画","4 画"],a:["A"],
   e:"「一」就是单独的一横，一画。",v:{ch:"一",label:"看笔画"}},
  {t:"s",q:"下面哪个字是「人」？",o:["入","人","八","大"],a:["B"],
   e:"「人」一撇一捺，像人侧身站着。",v:{label:"看拼音选字",py:"rén"}},
  // …
];
```

| 字段 | 含义 |
|---|---|
| `t` | 题型（`s`=单选） |
| `q` | 题干 |
| `o` | 选项数组 |
| `a` | 答案**字母**（`["A"]`），不是数字下标 |
| `e` | 答案解析（必填，家长靠它陪孩子复习） |
| `v` | 玩法附加数据（`ch` 生字 / `py` 拼音 / `label` 提示语） |

> ⚠️ **三个已踩过的坑**（详见 `internal/web/game_test.go` 注释）
> 1. 必须 `const ALL = [` —— 写成 `var ALL =` 解析为 0 题
> 2. 注释里若也出现 `const ALL = [` 字面量，`strings.Index` 会命中注释
> 3. `a` 必须用字母且**带引号** `a:["B"]`；用数字或裸 `B` 会让 `readArray` 返回空数组、整题被丢弃

### 4.4 六种玩法

| MODE | 玩法 | 用在 |
|---|---|---|
| `choice` | 四选一 | 识字、拼音、图形、数的认识 |
| `spell` | 看拼音组字 / 拖音节 | 汉语拼音单元 |
| `pair` | 连线配对 | 生字组词、反义词 |
| `count` | 数一数 | 数一数、比多少 |
| `compare` | 比大小（>、<、=） | 数的比较 |
| `calc` | 口算闯关 | 20 以内加减法 |

### 4.5 性能

- 单文件 ~21KB，纯静态，无外部依赖、无构建
- 换行符统一 CRLF（与项目其它内容文件一致）
- 无图片资源，无网络请求

## 六、架构决策：独立扫描器

游戏题**不进入** `textbook.Tree`：

- 若把 `game` 加进 `textbook.QType`，会牵动导航 / 归档 / 首页所有按题型分支的逻辑，违反最小改动原则
- `game.go` 内自持 `GameStore` + `parseGamePath`，与 `textbook` 包零耦合
- **删掉整个 `game.go` 即游戏功能消失，其它模块零影响**
- `TestGameStoreIgnoresBankFiles` 钉住这一保证（choose/judge 课程目录不会被误收为游戏）

学段白名单自持，因为 `textbook.NormalizeStage` / `StageCN` 对未知值**原样返回**，不能用作把关。
